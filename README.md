# palworld-assets

Тайлы подложки и картинки из окон меток для интерактивной карты [Palworld](https://broskiplay.ru/palworld-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/<z>/<x>/<y>.webp` и `tiles/manifest.json` — список существующих тайлов (z = 8..13)
- `popups/<id>.webp` — картинки из окон меток (id — первые 12 символов UUID оригинала)
